# Agenda

Welcome to dbt@scale part 2! 

This is a 2-day Hackathon event organized by Xebia and hosted by DPG. 

## Overview

There are now two working dbt projects in the MediaPulse analytics platform. During the workshop you will:

- Fix errors in the dbt pipeline
- Extend the project to include new data

## Topics

The topics will be as follows:

### Group 1: Next level dbt

- **dbt Modeling refresh** - configuring sources, tests, models using the correct steps
- **Bug fixing** - reading real production line breakages and fixing project issues
- **Seeds** - pulling in information to improve efficiency and code readability
- **Snapshots** - applying snapshots to create slowly changing dimensions (SCDs) type II
- **Next level testing** - Using test configurations and writing custom generic tests

### Group 2: Optimization and best practices

- **dbt modeling best practices** - review the best practices in a dbt project
- **Incremental modeling** - implement the best incremental strategies for specific use cases
- **Jinja review** - how to use jinja to elevate your project
- **Macros** - implement macros, for example to change the target schema based on environment
- **Advanced testing** - writing custom generic tests

### Group 3: Multi-project deployment best practices

- **Evaluate the project** - use `dbt-project-evaluator` to audit existing projects and improve best practices
- **Package tests** - apply tests from `dbt-expectations` and `elementary` 
- **Multi-project workflows** - apply model contracts, groups to expose models to other projects
- **dbt mesh** - Add dependencies to other projects and set up the right infrastructure to allow for ongoing maintenance
- **CI/CD pipelines** - set up dbt Cloud jobs and build CI/CD pipelines to maintain effective deployment 

### Group 4: Power Users

- **Multi-project workflows** - apply model contracts, groups to expose models to other projects
- **dbt mesh** - Add dependencies to other projects and set up the right infrastructure to allow for ongoing maintenance
- *Further topics will be discussed with the advanced group*
